# Echo 小手机

原生 HTML、CSS、JavaScript ES Module 实现的浏览器 AI 小手机。入口为 `小手机/lock-screen.html`，建议通过本地 HTTP 服务运行，例如：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory 小手机
```

打开 `http://127.0.0.1:8765/lock-screen.html`。API 需要供应商允许浏览器 CORS；文字模型目前只支持 OpenAI Chat Completions 兼容协议。HTTPS 为默认要求，localhost/127.0.0.1 的本地开发接口允许 HTTP。

## 工程边界

- 保留现有 UI、CSS 设计 Token、颜色、圆角、字体、毛玻璃和 HTML 布局层级；美化功能不在当前重构范围。
- 不引入运行时 UI 框架或第三方 UI 库，沿用现有图标与字体资源。
- 页面通过 `chat-app.js` 初始化；允许修改既有逻辑、移除重复实现。API 协议只在 `api.js` 实现，数据逻辑只在 `*-state.js` 实现。不要向文件末尾追加第二套业务处理器。
- 页面不得自行写聊天、档案、记忆等业务存储 key。存储失败必须可见，禁止通过截断原始历史来伪装保存成功。
- 动态文本必须作为文本处理；图片只使用受校验的本地栅格图片 data URL。上传先压缩，解码失败不能回退到未经限制的原文件。

## 数据与备份

现有 v1 业务 key 保持可读，兼容旧内联头像以及 `echo-conv-avatar-v1.*`。新保存的业务图片放在不可变 `echo-business-asset-v2.*` key，JSON 保留引用；图片写入和主记录提交失败时不删除旧数据。主题资源 key 不变。草稿用独立小记录 `echo-chat-drafts-v2`，输入合并写入，不再重写全部聊天历史。

回复有稳定的消息 ID 和 `turnId`。完整一轮先保存，再按照原有分段节奏展示；新轮次重新生成按整轮替换，替换失败保留原结果。刷新后的未完成请求标记为中断。

更新到本分支前，应先从现有浏览器导出数据。新版本世界页的已有“备份/恢复”按钮已接通，备份文件包含聊天、资料、记忆、动态、主题资源和草稿，**默认不含 API Key**。恢复只导入 Echo 所属 key；同一接口来源下保留当前浏览器已有 Key，不从文件导入凭据。备份仍含私人聊天和档案，请自行保管。

恢复先校验所有条目；运行中写入失败会尽力回滚本次更改，但 localStorage 多 key 不具备崩溃原子性。浏览器进程中途退出、跨标签页同时写入，仍需要后续 IndexedDB 事务化解决。不会自动删除旧消息或批量清理旧资源。

原版本不理解新图片引用和草稿 key，**不能直接把代码退回原版当作完整回滚**。更新前保留原始浏览器数据导出；新版本使用后还需导出当前备份，保留新产生的消息及资源，再进行版本回退或转换。

## 当前实现范围

首批完成：修复聊天入口阻断、存储破坏性降级、资料覆盖、动态 HTML 注入、首次创建、消息编辑、空列表、创建模式切换；收拢非美化业务 CRUD；统一三种回复方式；补齐参数/档案/有来源记忆注入及流式失败收尾。

“连接 MCP”原控件目前仅负责检测文字模型端点：401/403 显示认证失败；成功也会明确提示 MCP 未接入。没有 MCP 工具调用能力。世界书内容导入、世界书 prompt 注入、朋友圈评论等仍未实现，不会向模型注入虚构条目。

IndexedDB 全量迁移、跨标签页聊天事务协调、长历史分页、资源回收和精确 token 预算属于后续独立批次。当前上下文采用带输出预留的字符预算，不等同于供应商精确 token 计数。

## 开发验证

开发工具要求 Node.js 24；浏览器运行不需要 Node 或 npm。

```sh
cd 小手机
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

已安装 Chromium 时可使用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`。

- `check` 检查未定义标识符等问题，避免“语法正确但调用缺失函数”。
- `test` 覆盖配额失败、旧数据、图片提交、档案 patch、空态、备份恢复、SSE 边界、参数和 UI 源码保护。
- 浏览器测试使用假 Key 和模拟 API，不产生实际模型费用；覆盖全部 16 页及聊天、编辑、群聊、重新生成、刷新、失败恢复和跨标签页记忆同步。
- UI 基线锁定所有页面 CSS、HTML 标签层级和整个美化控制器；没有以视觉优化为名修改样式。
- 真机 Operit WebView、实际供应商 CORS 和大数据量性能，仍需在用户设备验收。

详细实施记录见 `小手机/REFACTOR_NOTES.md`。
