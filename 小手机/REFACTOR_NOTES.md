本批以 GitHub 当前代码为基础，同步了 main 新增的网页启动配置；不再把旧交接环境当作实现约束。

- 新增 `database-state.js`，将全部非美化业务数据迁至 IndexedDB。消息使用会话/顺序主键和身份/轮次/状态索引。
- 迁移校验数量、逐项内容和图片引用，完成标记与原始快照同事务提交。坏数据、配额失败或写入异常不会切换半成品数据库；原 localStorage 保留。成功后不重复导入，不双写。
- 业务命令使用异步事务和新鲜数据库值；资料/记忆/动态也参与并发保护。资料档案编辑只提交真正修改的字段。

## 第三批：回复服务、上下文预算与后台维护

- 从页面控制器抽出无 DOM 依赖的 `reply-service.js`，单聊、群聊和重新生成继续共用流程。页面仅通过回调呈现状态、流式正文和分段回复。每轮固定设置快照，错误更新通过数据库查询消息，不依赖当前分页缓存。
- 用户消息追加与草稿清理合并为同一事务。生成取消与错误恢复维持原行为；过多段落合并到最后一段，限制展示定时任务数量并完整保存正文。
- 新增纯函数 prompt 构建器和模型预算模块。最新真实用户消息先于历史合并与裁剪，避免连续用户消息或大段群聊回复把当前问题挤掉。可选背景按预算加入，存储原文不变。
- 已知 GPT-4o/4.1、GPT-4/3.5 模型使用本地分词表，未知模型保守按 UTF-8 字节估算；统一预留输出与协议开销，超限不联网。识别的推理模型使用对应输出字段并省略不支持的采样参数。计数精度限于已匹配的文本编码，供应商封装仍可能不同。
- `js-tiktoken` 固定到 1.0.21，上游提交、生成器版本、字节数、SHA-256 和 MIT 许可随资源保存。浏览器按需加载对应编码器，无外部 CDN。CI 重建校验，开发工具路径不由静态服务器公开。
- 自动记忆使用独立、可取消的后台任务，每页最多并行两项。提交时检查会话、角色及完整源回复 ID 集合；重新生成成功会原子移除该轮自动记忆，手工记忆保留，晚到旧结果被拒绝。
- 图片回收改为游标扫描并在备份下载发起后运行；支持取消及删除事务回滚，不在聊天启动时扫描全部历史，不删除旧迁移来源。

本批验证：43 项单元/数据/API/启动测试及 25 组 Chromium 浏览器回归通过，ESLint 通过。新增覆盖中英文分词、特殊文本、输出字段、预算溢出前的零请求、无 DOM 调度、超多分段不丢正文、草稿事务故障注入、重新生成与记忆晚到、游标资源回收与取消回滚。首页、美化页、锁屏截图与审查基线逐像素一致，CSS、HTML 标签结构和美化控制器源码保护继续通过。未调用真实付费模型，未合并 main。

依赖审计：新增的分词与构建依赖没有命中漏洞报告。现有 ESLint 10 的 minimatch 依赖链仍有 GHSA-g3hv-75wg-m249（3 项中等级关联报告），只用于开发期固定 glob，不进入浏览器。npm 建议回退到已停止维护的 ESLint 9，故保留当前受支持版本，等待上游适配 minimatch 11；未强制覆盖不兼容的大版本。
